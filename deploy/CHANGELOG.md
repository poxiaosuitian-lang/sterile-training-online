# 更新记录

## 1.0.92（2026-10-22）

- 后台增加游戏维护开关、公告标题与正文编辑，设置保存在数据库，默认开放。
- 新版玩家登录后先确认开放状态；维护期间停留主题公告页，每 15 秒自动检查，也可刷新、退出账号或检查更新。
- 服务器拒绝维护期间的新关卡请求（包括开发者模式），已开始的关卡仍可结算，账号成绩保留。
- 公告中的开放时间为说明文字，由管理员手动结束维护，不会按文字自动定时开放。
- 联网 APK 1.0.92 / 93。需更新服务器 API 和 APK；旧 APK 无法显示新公告页，但开始关卡同样受服务端限制。

## 1.0.91（2026-10-21）

- 管理后台新增手动添加、删除玩家、跨页全选、批量重置进度，以及开放/关闭自行注册。
- 支持私下导入学号与姓名名单；已有账号不覆盖密码和成绩，冲突名单拒绝导入。
- 玩家设置新增修改密码，修改后旧登录凭证失效；已删除账号不可继续访问。
- 重置清理成绩、进度和旧游戏会话；客户端停止补传已重置的会话。
- 开发者模式默认关闭，校验码由管理员设置并在服务器验证；授权后完成关卡照常计入正式进度和成绩。移除排行榜接口及客户端入口。
- 合并 1.0.90 的浅色主题更新弹窗，并统一首页同步提示条。
- 联网 APK 1.0.91 / 92。本次需要备份数据库并重建 API，启动时自动迁移；不能只更新 APK。
- 名单不包含在 GitHub、Docker 镜像或 APK 中，部署时通过私有文件或管理后台导入。

- 不再向玩家展示原始发布说明中的服务器维护文案。更新下载地址及版本比较逻辑不变。

- 联网 APK 1.0.90 / 91，保持原签名和正式服务器地址；新弹窗在安装本次 APK 后生效。

## 1.0.89（2026-10-21）

- 五关正确操作统一使用合成提示音，错误操作使用污染提示音，补齐找茬、迷宫答题、铺巾与开包等操作反馈。
- 每关结算通过后播放包含“太棒了”的通关音效，随音效开关和音量设置生效；重复提交不重复播放。语音随 APK 提供，无需联网合成。
- 第四关再次点击消毒棉片可取消瞄准且不消耗道具；使用其他道具也退出瞄准。
- 十个指甲的点击与拖放区域增大，手机上至少 44×44 逻辑像素，支持选择工具后点击指甲边缘启动护理。
- 联网 APK 1.0.89 / 90，沿用原包名、发布签名和 wu.yikui.fun 地址；评分规则保持 1.0.88。
- 已部署 1.0.88 的服务器仅需执行 `python3 tools/update_apk.py` 同步安装包，无需重建 API。

## 1.0.81（2026-10-05）

- 修正物品布局拖放时图像与实际落点偏移的问题；无菌巾包和清洁用品均可先放，拖错或拖到区域外后可直接重试。
- 第一关有效期贴标改为提交时判定：任选四个选项之一均可点击“贴上标签”，选择过程不显示正确答案或到期时间，也不扣分。错误提交显示红色提示并计一次失误，正确提交后才完成贴标。
- 回归验证覆盖 8 件物品、4 种手机尺寸，检查遍历选项不会泄露答案、取消不贴标、错误提交可重试，以及正确贴标后正常分区。
- 修正第二关第三场景“持物钳 · 操作排查”的第四处判点：使用的钳子不是无菌持物钳。
- 点击手持钳身或两侧指环都计入同一处错误，重复点击不重复计数；判定区域避开“握持位置错误”和“钳端触碰外壁”，另外三处判点保持独立。
- 第四处找到后的对勾放在钳环区域，避免被细长钳身的点击轮廓裁切。
- 去掉本场景原先误配置的“右侧筒内浸泡深度不足”判点，知识要点同步调整。
- 单机版、联网版共用修复后的点击区域，后端答案与单机评分样例同步更新。更新服务端时重新构建 API 容器。
- 验证：83 项有效期、第一关、找茬与单机评分测试，以及 7 项物品布局拖放测试通过，43 项后端测试通过，Flutter 静态分析和后端构建通过。点击回归覆盖 592×333、800×360、1097×617 逻辑尺寸；未连接模拟器或真实手机。
