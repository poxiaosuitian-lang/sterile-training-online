## 1.0.81（2026-10-05）

- 修正物品布局拖放时图像与实际落点偏移的问题；无菌巾包和清洁用品均可先放，拖错或拖到区域外后可直接重试。

- 第四处找到后的对勾放在钳环区域，避免被细长钳身的点击轮廓裁切。
- 去掉本场景原先误配置的“右侧筒内浸泡深度不足”判点，知识要点同步调整。
- 单机版、联网版共用修复后的点击区域，后端答案与单机评分样例同步更新。更新服务端时重新构建 API 容器。
- 验证：83 项有效期、第一关、找茬与单机评分测试，以及 7 项物品布局拖放测试通过，43 项后端测试通过，Flutter 静态分析和后端构建通过。点击回归覆盖 592×333、800×360、1097×617 逻辑尺寸；未连接模拟器或真实手机。
